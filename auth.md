# WebPKit authentication and access

WebPKit is a static, browser-only image converter. There are no accounts, API keys, OAuth scopes, or protected resources.

## Public access

- HTML pages: https://webpkit.app/
- Markdown twins: append `.md` to a page path, for example https://webpkit.app/webp-to-png.md
- AI summary: https://webpkit.app/llms.txt
- Full AI summary: https://webpkit.app/llms-full.txt
- Sitemap: https://webpkit.app/sitemap.xml

## Agent guidance

- All content is read-only.
- Images are processed locally in the browser and are never uploaded.
- There is no upload endpoint, no write API, and no payment flow.
- Use the public pages and Markdown twins as the source of truth.
- For corrections, email wk@webpkit.app.
